**Energy Vision and Appliance Diagnostic Assistant**
1) Developed a web-based application that provides personalized energy-saving recommendations based on weather conditions and an AI-powered appliance diagnostics assistant.
2) Integrated Google Gemini and OpenStreetMap APIs to generate intelligent responses with location-aware weather insights and recommendations.
3) Built the application using Python and Streamlit, and deployed it on Render with Render PostgreSQL database support for public web access.
4) Streamlit web link - https://energy-app-ol1i.onrender.com
